# 🌕 Trung Thu Games Collection

Một bộ sưu tập gồm 5 tựa game mini giải trí với chủ đề Tết Trung Thu được xây dựng bằng HTML5 Canvas, CSS3 và Vanilla JavaScript. Dự án mang đến trải nghiệm đồ họa đẹp mắt, hiệu ứng sống động và hệ thống lưu điểm xếp hạng ngay trên trình duyệt.

## 🎮 Các Tựa Game Bao Gồm:

1. **Hứng Bánh Trung Thu**: Di chuyển rổ để hứng bánh, lồng đèn, ngôi sao và né đá, bom.
2. **Đập Chuột Cứu Bánh**: Thử thách phản xạ bằng cách đập chuột thường và chuột vàng để ghi điểm, tránh đập trúng Thỏ Ngọc. Chú ý: Đập hụt 5 lần sẽ thua!
3. **Thỏ Ngọc Bay Lên Trăng**: Trò chơi mang phong cách Flappy Bird. Giúp Thỏ Ngọc bay qua các chướng ngại vật ống tre.
4. **Trí Nhớ Đêm Trăng**: Lật thẻ bài tìm các cặp hình giống nhau trước khi hết giờ. Nếu lật sai 7 lần, bạn sẽ thua.
5. **Sinh Tồn (Né Rắn)**: Trò chơi sinh tồn, điều khiển Thỏ Ngọc (dùng phím WASD hoặc Joystick) né tránh những con rắn đang lao tới từ mọi phía và ăn bánh trung thu để ghi điểm.

## ✨ Tính Năng Nổi Bật

- **Bảng Xếp Hạng (Leaderboard):** Tích hợp tính năng lưu tên và điểm số của người chơi bằng `localStorage`, hiển thị Top 5 người có điểm cao nhất ở mỗi game.
- **Tối Ưu Giao Diện & Hitbox:** Các thao tác chạm và vùng va chạm (hitbox) được căn chỉnh tỉ mỉ để đem lại cảm giác mượt mà và công bằng nhất.
- **Tự Động Xử Lý Xoá Nền:** Tính năng tự động đọc và lọc màu nền (Chroma Key) của các sprites hình ảnh bằng Canvas.
- **Chụp Ảnh Phạt (Quà Người):** Chế độ đặc biệt tự động chụp ảnh người chơi lúc thua cuộc kèm bộ lọc làm đẹp (Beauty Filter).
- **Phím Điều Khiển Đa Dạng:** Hỗ trợ phím cứng (WASD, Mũi tên), Chuột và Màn hình cảm ứng (Joystick ảo).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

1. Cài đặt các gói thư viện cần thiết:
   ```bash
   npm install
   ```

2. Khởi chạy máy chủ phát triển (Vite):
   ```bash
   npm run dev
   ```

3. Mở trình duyệt và truy cập vào địa chỉ cục bộ (thường là `http://localhost:5173`).

## 🛠 Công Nghệ Sử Dụng
- **Core:** HTML5, CSS3, JavaScript (ES6+).
- **Đồ họa:** Canvas 2D API.
- **Build Tool:** Vite.
